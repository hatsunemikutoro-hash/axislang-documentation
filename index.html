Syntax

Axis is an assembly-like language with characteristics of the brainfuck language, and its goal is to be a didactic language

therefore, each axis instruction can be represented as INSTRUCTION [ARGS] may have one or more arguments depending on the instruction

In addition to not being case sensitive, there is not much for me to say because the language is still in progress

Examples

Hello Axis!

output

Two Sum

Memory Manipulation
MOVE 2

PRINT
