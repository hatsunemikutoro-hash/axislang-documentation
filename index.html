Introduction

Welcome to the official documentation for the Axys programming language!

Axys is an instruction- and memory-based programming language that combines the concepts of Assembly and Brainfuck.

It runs on a large memory array containing 256 positions. Each position has its own address and value, and your role is to manipulate this memory through different instructions to create various types of programs.

Axys was designed to be the intermediate bridge between the transparency of low-level programming and the simplicity of high-level programming, allowing beginners to understand low-level concepts without feeling lost.

Instructions

Axys instructions follow the format: INSTRUCTION [ARGS]. The language is case-insensitive.

Memory & Movement Instructions

  • MOVE <address> - Move the cursor to a specific memory cell
  • SET <value> - Set the current cell to a value
  • [address] -> name - Create an alias for a memory address

Arithmetic Instructions

  • ADD <value> - Add a value to the current cell
  • SUB <value> - Subtract a value from the current cell
  • MULT <value> - Multiply the current cell by a value
  • DIV <value> - Divide the current cell by a value (cannot divide by zero)

Output Instructions

  • PRINT [value] - Print a numeric value (or current cell if no argument)
  • PRINTC <value> - Print as a character (or string if a string literal is provided)

Control Flow

  • JUMP <line> - Jump to a specific line in the program
  • EXIT - Terminate the program

Advanced Features

  • *<address> - Dereference: use the value at an address as a value
  • [address] - Indexing: use an address indirectly

Memory & Cells

Axys uses a virtual machine with 256 memory cells, numbered from 0 to 255.

When you start a program, all cells are initialized to 0. The cursor points to the current cell being manipulated.

You can:

  • Move the cursor to different cells with MOVE
  • Modify the value at the current cell with SET, ADD, SUB, MULT, DIV
  • Read values from cells using dereferencing with the * operator
  • Create named aliases for addresses to make programs more readable

Examples

Hello, Axys!
printc "Hello, Axys!"
Output
> Hello, Axys!
Simple Addition
set 5
add 3
print
Output
> 8
Memory Manipulation
@ Set cell 0 to 10
set 10

@ Add 5 to cell 0
add 5

@ Print the result
print
Output
> 15
Working with Multiple Cells
@ Store 20 in cell 0
set 20

@ Move to cell 1 and store 7
move 1
set 7

@ Move back to cell 0 and dereference cell 1
move 0
add *1

@ Print result (20 + 7 = 27)
print
Output
> 27
Using Aliases
@ Create aliases
[0] -> health
[1] -> damage

@ Set values
move 0
set 100
move 1
set 20

@ Calculate damage
move 0
sub *1

@ Print health after damage
print
Output
> 80
